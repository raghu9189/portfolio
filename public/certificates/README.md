# Adding Your Convocation Ceremony Images

To add your MCA convocation ceremony photos to the portfolio:

## Step 1: Add Your Images

1. Copy 6 of your convocation/office ceremony photos to:
   ```
   public/certificates/
   ```

2. Rename them as:
   - `convocation-1.jpg` (first photo)
   - `convocation-2.jpg` (second photo)
   - `convocation-3.jpg` (third photo)
   - `convocation-4.jpg` (fourth photo)
   - `convocation-5.jpg` (fifth photo)
   - `convocation-6.jpg` (sixth photo)

## Image Gallery Features

✨ The gallery includes:
- **Image slider** with smooth transitions
- **Navigation arrows** to browse through photos
- **Dot indicators** showing current image
- **Image counter** (e.g., "1 / 6")
- **Auto-generated captions** with university name
- **Responsive design** that works on all devices
- **Hover effects** and animations

## Image Specifications

**Recommended:**
- Format: JPG or PNG
- Resolution: 1920x1080px or higher for best quality
- Orientation: Landscape works best (but portrait is supported)
- File size: Under 1MB each (optimize if larger)
- Content: Convocation ceremony moments, office photos, group photos, etc.

## Tips for Best Results

1. **Choose diverse photos**: Mix of solo shots, group photos, ceremony moments, office events
2. **Good lighting**: Select well-lit photos for better display
3. **High quality**: Use high-resolution photos (avoid blurry images)
4. **Crop if needed**: Crop to highlight the important parts

## File Structure

```
public/
  └── certificates/
      ├── convocation-1.jpg
      ├── convocation-2.jpg
      ├── convocation-3.jpg
      ├── convocation-4.jpg
      ├── convocation-5.jpg
      └── convocation-6.jpg
```

## Note

- The Bachelor's degree section will display a simple graduation cap icon (no images needed)
- Only the Master's degree section has the image gallery
- All 6 images are now supported in the gallery

Once added, your convocation photos will automatically appear with smooth transitions and navigation controls! 📸🎓
